AirRadar

Install in one click

Flash AirRadar to your Waveshare ESP32-S3-Touch-LCD-7 directly from this page — no IDE, no drivers to fight.

Requires desktop Chrome or Edge. Connect the board by USB-C first.

v7.2.0-beta.1

This build fixes a memory leak that starved the device of RAM about 25 minutes into every boot, which silently stopped weather, route and airline-logo lookups. Free internal memory now holds steady instead of falling ~72 B/s. It is marked beta because the fix has hours of testing behind it, not weeks — it is still the build you want. Details in issue #1.

Your browser can't flash over USB — use desktop Chrome or Edge. Serial access was blocked — allow it and retry.
  1. Plug the board into your computer with a USB-C data cable.
  2. Flip the onboard UART switch to the flashing position if upload fails.
  3. Click Connect & Install and pick the USB JTAG/serial or wchusbserial port.
  4. Wait for the flash to finish — the radar boots straight into first-run setup.
